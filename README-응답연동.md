# 응답 → 구글 시트(엑셀) 연동 방법

1. 구글 드라이브에서 새 **구글 스프레드시트** 생성 (이름 예: `청첩장 모임 응답`)
2. 메뉴 **확장 프로그램 → Apps Script** 클릭
3. 기본 코드를 지우고 `apps-script.gs` 내용을 전부 붙여넣기 → 저장
4. 우측 상단 **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 권한 승인(고급 → 이동 허용) 진행
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`) 복사
6. `invitation.html` 안의 `const SHEET_URL = "";` 따옴표 안에 붙여넣기
7. 테스트: 페이지에서 응답 보내기 → 시트의 `응답` 탭에 행이 추가되는지 확인
8. 엑셀로 받기: 시트에서 **파일 → 다운로드 → Microsoft Excel(.xlsx)**

## 참고
- 시트 `H~I` 열에 참석 인원 합계 / 참석·불참 응답 수가 자동 집계됩니다.
- 코드를 수정하면 **배포 → 배포 관리 → 새 버전**으로 다시 배포해야 반영됩니다.
- 웹 앱 URL을 아는 사람은 누구나 응답을 보낼 수 있으니 URL은 청첩장 페이지에만 쓰세요.

## 안 쌓일 때 체크리스트
1. **웹 앱 URL을 브라우저 주소창에 직접 열기** → `RSVP endpoint is running`이 보여야 정상 (로그인 화면이 뜨면 액세스 권한이 '모든 사용자'가 아님)
2. Apps Script 편집기에서 함수 선택칸을 `testRow`로 두고 **실행** → 권한 승인 후 시트에 '테스트' 행이 생기는지 확인
   - 오류 `스프레드시트를 찾을 수 없습니다`가 나오면: 시트 밖(script.google.com)에서 만든 독립 스크립트이므로, 코드 상단 `SPREADSHEET_ID`에 시트 ID를 넣기
3. 코드를 고쳤다면 **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포** (새 배포를 만들면 URL이 바뀌니 HTML의 `SHEET_URL`도 교체)
4. 시트의 탭 이름이 `응답`으로 자동 생성되니, 처음에는 `응답` 탭을 확인
